同步与备份

怎么让手机能打开这个页面？（点开）

手机要访问，页面本身必须先挂到网上。三种做法，按省事程度排：

  1. GitHub Pages（推荐，免费且长期）：新建一个仓库传上 tiku.html → Settings → Pages → Source 选 main 分支 → 得到 https://用户名.github.io/仓库名/tiku.html
  2. 任意静态托管：Vercel / Netlify 拖拽上传，或腾讯云 COS、阿里云 OSS
  3. 临时用（同一个 WiFi）：在放文件的目录执行 python3 -m http.server 8000，手机浏览器打开 http://电脑局域网IP:8000/tiku.html。电脑关机就失效

传上去之后，用那个网址打开页面再来点上面的「生成手机查看链接」， 生成的链接才是手机能用的。

怎么弄到这个令牌？（点开）
  1. 手机或电脑浏览器打开 github.com 并登录
  2. 头像 → Settings → 左栏最下 Developer settings
  3. Personal access tokens → Tokens (classic) → Generate new token (classic)
  4. Note 随便写，Expiration 选 No expiration
  5. 只勾选 gist 这一项，其它全不要勾 → Generate
  6. 复制生成的 ghp_… 粘到上面，点「立即同步」

令牌相当于钥匙，会存在本机浏览器里。请务必只勾 gist 权限， 这样即使泄露也只能读写你的 Gist，动不了仓库和账号。

此模式只读不写：每次打开会拉取最新数据并与本地合并， 适合「电脑维护、手机只看」。
